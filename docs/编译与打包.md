# 编译与打包

从干净环境到产出三个东西：

1. `dist\NFC Mini Studio\NFC Mini Studio.exe` —— 绿色版主程序
2. `installer\dist\NFC Mini Studio 安装程序.exe` —— 一键安装包
3. `android\NFCMiniReader.apk` —— 手机读卡器 APK

---

## 一、环境准备

### 桌面端必需

| 项 | 版本要求 | 本项目验证版本 |
| --- | --- | --- |
| Windows | 10 / 11 x64 | Windows 11 |
| Python | 3.10+ | 3.14.3 |

Python 依赖：

```powershell
cd 项目根目录
python -m pip install --no-cache-dir -r requirements.txt
```

`requirements.txt` 内容：

```
bleak>=0.22.0          # 蓝牙 BLE
pywebview>=5.0         # 原生窗口承载前端
Pillow>=10.0.0         # 壁纸处理
pyinstaller>=6.0       # 打包
numpy>=1.26.0          # 破解数值计算
numba>=0.59.0          # 破解 JIT 加速
```

实际还用到（pip 会随上面自动装或已在标准库）：

- `pycryptodome` / `pycryptodomex` —— AES（云端 token 解密）
- `pyngrok` —— 可选内网穿透
- `pyzipper` —— 导入导出压缩包

### Android 端必需

| 项 | 版本要求 | 本项目验证 |
| --- | --- | --- |
| JDK | 17 | Microsoft OpenJDK 17.0.19.10 |
| Android SDK | platform 34 + build-tools 34.0.0 | `C:\Android\Sdk` |
| Gradle | 8.7 | `C:\Android\gradle\gradle-8.7` |
| Android Gradle Plugin | **8.6.x** | 8.6.1 |

> ⚠️ **AGP 必须是 8.6.x**。AGP 8.7 要求 Gradle ≥ 8.9，而本机是 Gradle 8.7，会报 `Minimum supported Gradle version is 8.9`。

`build_android.py` 会自动找这些路径：

```python
find_sdk()    # ANDROID_HOME / ANDROID_SDK_ROOT / C:\Android\Sdk
find_jdk()    # JAVA_HOME / C:\Program Files\Microsoft\jdk-17.*-hotspot / ...
find_gradle() # GRADLE_HOME / C:\Android\gradle\gradle-8.7 / ...
```

找不到会明确报错告诉你该设哪个环境变量。

## 二、构建桌面端

### 一条命令全量构建

```powershell
python build_all.py
```

它做三件事：

```
1. build_app()       PyInstaller onedir → dist\NFC Mini Studio\
2. sync_payload()    复制 dist\NFC Mini Studio → installer\payload\
3. build_installer() PyInstaller onefile → installer\dist\NFC Mini Studio 安装程序.exe
```

耗时约 3~8 分钟（取决于机器）。

### 分步构建

```powershell
python build_all.py app        # 只打主程序
python build_all.py payload    # 只同步 payload
python build_all.py installer  # 只打安装程序（需先有 payload）
```

### build_all.py 关键参数

```python
APP_NAME = "NFC Mini Studio"
SETUP_NAME = "NFC Mini Studio 安装程序"
ICON = ROOT / "assets" / "app.ico"
TMP = ROOT / "build_tmp"
```

主程序打包参数：

```
--noconfirm --clean --windowed --onedir
--name "NFC Mini Studio"
--icon assets/app.ico
--add-data "app/web;app/web"
--collect-all webview
--collect-all bleak
--collect-all numpy
--collect-all numba
--collect-all llvmlite
--hidden-import tkinter
```

> `--collect-all webview` 是必须的：pywebview 有平台相关的子包和二进制，不收集会运行时找不到。
> `--collect-all llvmlite` 是 numba 的依赖，缺了破解功能会崩。

### 产物

```
dist\NFC Mini Studio\
├── NFC Mini Studio.exe     ← 双击运行
├── _internal\              ← 依赖与前端资源
└── ...
```

整个文件夹就是绿色版，拷走就能用。

## 三、构建安装程序

安装程序本身也是 PyInstaller 打的，只是把整个 payload 塞进去。

```powershell
python build_all.py installer
```

参数：

```
--noconfirm --clean --windowed --onefile
--name "NFC Mini Studio 安装程序"
--icon assets/app.ico
--add-data "installer/payload;payload"
```

产物：`installer\dist\NFC Mini Studio 安装程序.exe`（约 130~145 MB，因为内嵌了完整主程序）。

> **为什么用 onefile**：安装程序必须是单个 exe 才能发给别人。onefile 启动时会先自解压到临时目录，所以第一次双击会慢 2~5 秒。

### 安装程序支持的命令行

```powershell
# 静默安装到默认路径
& ".\NFC Mini Studio 安装程序.exe" --silent

# 静默安装到指定路径
& ".\NFC Mini Studio 安装程序.exe" --silent --target "D:\Tools\NFCMiniStudio"

# 静默安装并立即启动
& ".\NFC Mini Studio 安装程序.exe" --silent --launch
```

### 安装程序做了什么

`installer\installer.py` 的逻辑：

1. 解压内嵌的 `payload/` 到目标目录（默认 `%LOCALAPPDATA%\Programs\NFC Mini Studio`）
2. 创建开始菜单快捷方式
3. 可选创建桌面快捷方式
4. 写注册表卸载项（`HKCU\Software\Microsoft\Windows\CurrentVersion\Uninstall\NFC Mini Studio`）
5. 可选立即启动

**不需要管理员权限**——全部写在 HKCU 和用户目录里。

## 四、构建 Android APK

### 一条命令

```powershell
python build_android.py
```

### 它做什么

```
1. find_sdk() / find_jdk() / find_gradle()   定位工具链
2. mirror_to_ascii_tree()                     把 android/ 镜像到 %TEMP%\nfcmreader-build
3. 写 local.properties                        sdk.dir=...
4. 补 android.overridePathCheck=true          绕过中文路径检查
5. gradle assembleRelease --no-daemon --console=plain
6. 找 app\build\outputs\apk\release\app-release.apk
7. 复制到 android\NFCMiniReader.apk
```

### 为什么必须先镜像到 ASCII 路径

AGP 会检查工程路径：

```
Your project path contains non-ASCII characters.
This will most likely cause the build to fail on Windows.
```

本项目在 `E:\我的项目\NFC读卡工具NFCMiniStudio`，用户名也可能是中文（我的就是 `刘子墨`），路径必然含非 ASCII。所以脚本把工程复制到 `%TEMP%\nfcmreader-build`（纯 ASCII）再构建。

也可以在 `gradle.properties` 加 `android.overridePathCheck=true` 强行跳过检查，但有时仍会在别的地方（如 R 文件生成）踩坑。两个手段一起用最稳。

### 可选参数

```powershell
python build_android.py --debug      # 打 debug 版
python build_android.py --install    # 构建完成后 adb install -r
python build_android.py --no-clean   # 增量构建（快，但可能残留）
```

### 手动构建（调试用）

如果脚本出问题，可以手动来：

```powershell
$env:JAVA_HOME = "C:\Program Files\Microsoft\jdk-17.0.19.10-hotspot"
$env:ANDROID_HOME = "C:\Android\Sdk"
$env:ANDROID_SDK_ROOT = "C:\Android\Sdk"

# 镜像到 ASCII 路径
Remove-Item C:\nfcmreader-build -Recurse -Force -ErrorAction SilentlyContinue
Copy-Item "E:\我的项目\NFC读卡工具NFCMiniStudio\android\*" C:\nfcmreader-build -Recurse

Set-Location C:\nfcmreader-build
& "C:\Android\gradle\gradle-8.7\bin\gradle.bat" assembleRelease --no-daemon --console=plain
```

产物：`C:\nfcmreader-build\app\build\outputs\apk\release\app-release.apk`

验证：

```powershell
& "C:\Android\Sdk\build-tools\34.0.0\aapt.exe" dump badging app-release.apk
```

应该看到：

```
package: name='net.nfcreader.minireader' versionCode='2' versionName='1.1.0'
sdkVersion:'21'
targetSdkVersion:'34'
application-label:'NFC 手机读卡器'
```

再验证签名（应该是 `CN=NFC Mini Studio` 而不是 `CN=Android Debug`）：

```powershell
keytool -printcert -jarfile app-release.apk
```

### APK 签名说明

1.1.0 起使用**正式 release 签名**，证书在 `android/keystore/nfcmini-release.jks`，
密码在 `android/keystore.properties`（都随仓库公开）。

```gradle
signingConfigs {
    release {
        if (hasReleaseSigning) {
            storeFile rootProject.file(keystoreProps['storeFile'])
            storePassword keystoreProps['storePassword']
            keyAlias keystoreProps['keyAlias']
            keyPassword keystoreProps['keyPassword']
        }
    }
}
buildTypes {
    release {
        signingConfig hasReleaseSigning ? signingConfigs.release : signingConfigs.debug
    }
}
```

**为什么把私钥公开？**

- 这是免费开源工具，没有保护品牌的需求；
- 公开后任何人都能重建出**签名一致**的包，方便增量覆盖安装，不会出现「签名冲突，请先卸载」；
- 没有 `keystore.properties` 时自动退回 debug 签名，保证任何环境都能构建。

证书信息：`CN=NFC Mini Studio, OU=RC2 Unlock Project, O=RC2 Unlock Project, C=CN`，RSA 2048，有效期 30 年。

换成你自己的证书：

```powershell
& "$env:JAVA_HOME\bin\keytool.exe" -genkeypair -v `
  -keystore android\keystore\my-release.jks -alias mykey `
  -keyalg RSA -keysize 2048 -validity 10950 `
  -dname "CN=Your Name, O=Your Org, C=CN"
```

然后改 `android/keystore.properties` 的 `storeFile / storePassword / keyAlias / keyPassword`。

> ⚠️ 换了证书后，老用户升级必须先卸载旧版。

## 六、版本号在哪改

**唯一来源**：`app/paths.py`

```python
APP_VERSION = "3.0.0"
```

其他地方引用它：

- `app/web/index.html` —— 关于页显示（`id="aboutVer"`），是硬编码文本，要一起改
- `installer/installer.py` —— `APP_VERSION = "3.0.0"`，硬编码
- `app/web/css/style.css` / `macos.css` —— 注释里的版本号
- `android/app/build.gradle` —— `versionCode` / `versionName`

改版本时一次性全改，然后跑自检确认「私有接口就绪」那项显示新版本。

## 七、常见构建错误

| 错误 | 原因 | 解决 |
| --- | --- | --- |
| `Minimum supported Gradle version is 8.9` | AGP 8.7 + Gradle 8.7 | AGP 降到 8.6.1 |
| `Your project path contains non-ASCII characters` | 路径有中文 | 镜像到 ASCII 路径 / 加 `android.overridePathCheck=true` |
| `Could not find com.android.tools.build:gradle` | 仓库连不上 | `settings.gradle` 里阿里云镜像优先 |
| pip `Errno 13 Permission denied ... .whl` | pip 缓存目录权限 | `pip install --no-cache-dir` |
| PyInstaller 打完运行时 `ModuleNotFoundError: webview` | 没 collect-all | 加 `--collect-all webview` |
| 破解功能打包后崩 | 缺 llvmlite | 加 `--collect-all llvmlite` |
| 删除 `android\app\build` 报「目录不是空的」 | exFAT 删深层目录不可靠 | 用 `cmd /c rd /s /q "路径"` |
| 安装程序双击没反应 | onefile 自解压慢 | 等 2~5 秒；或换成 onedir 版本 |
| APK 安装报「解析包错误」 | minSdk 高于手机 | 本 APK minSdk 21（Android 5.0），太老的手机不支持 |
