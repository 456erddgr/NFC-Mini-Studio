## 一、安装

### 安装程序

双击 `installer\dist\NFC Mini Studio 安装程序.exe`。

- 默认装到 `%LOCALAPPDATA%\Programs\NFC Mini Studio`（当前用户目录，不需要管理员）
- 可以改路径、选是否建桌面快捷方式
- 装完可以勾「立即启动」
- 卸载：设置 → 应用 → NFC Mini Studio → 卸载

**静默安装**（脚本化场景）：

```powershell
& ".\NFC Mini Studio 安装程序.exe" --silent --target "D:\Tools\NFCMiniStudio" --launch
```

### 绿色版

`dist\NFC Mini Studio\` 整个文件夹拷走即可，双击 `NFC Mini Studio.exe` 运行。

配置和卡片存档在 `%APPDATA%\NFCMiniStudio\`，换机器时一起拷过去就能保留数据。

### 源码运行

```powershell
python -m pip install --no-cache-dir -r requirements.txt
python run.py
```

> Windows 上 pip 常因为缓存目录权限报 `Errno 13`，加 `--no-cache-dir` 能绕过。

## 三、连接读卡器（三种方式）

### 方式 A：蓝牙原厂读卡器（能力最全）

1. 读卡器开机（指示灯闪）。
2. **手机微信先退出小程序**——小程序会占用蓝牙。
3. 设备页 → 顶部分段选「蓝牙原厂」。
4. 点「一键扫描设备」，等 5~8 秒。
5. 列表里出现 `NFC Mini 2.0`（或 `U-XXXX`）→ 点它。
6. 状态变成「已连接」后，设备卡会显示固件版本、SN、电量。

连不上怎么办：

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 扫不到设备 | 读卡器没开机 / 没电 | 充电后重试 |
| 扫不到但手机能连 | 蓝牙被小程序占用 | 微信里点「关闭小程序」，或手机蓝牙先关掉 |
| 扫到但连不上 | 距离太远 / 干扰 | 靠近到 1 米内，避开 USB 3.0 接口 |
| 连上后马上断 | 电池太低 | 充电 |

### 方式 B：通用 PC/SC 读卡器

**第一步：启动 Windows 智能卡服务**

在**管理员 PowerShell** 里：

```powershell
sc config SCardSvr start= auto
net start SCardSvr
```

软件里点「检测 PC/SC 环境」也能看状态；如果是红的，点「复制修复命令」再粘到管理员 PowerShell 执行。

**第二步：插读卡器**

任意 PC/SC 标准读卡器。设备管理器 → 智能卡读卡器 → 能看到型号就成功了。

**第三步：连接**

设备页 → 选「通用读卡器」→ 点「扫描读卡器」→ 选中 → 「连接」。

设备卡会显示「PC/SC 通用读卡器」，能力矩阵里 `crack_device` / `read_id_card` / `lock_card` 是 ✕，其余是 ✓。

### 方式 C：手机读卡器

见 [第十节](#十手机当读卡器)。

## 四、寻卡

连接成功后，左侧点「寻卡」。

1. 把卡**平贴**在读卡器感应区（原厂读卡器中间；通用读卡器标有 NFC 图标处）。
2. 点「寻卡」或按 `F5`。
3. 卡片出现，显示：
   - **UID**（例如 `A1 B2 C3 D4`）
   - **卡类型**：IC 卡 / UID 卡 / 7 字节 UID 卡 / ID 卡
   - **SAK**、**是否可写**
   - **频段**：13.56 MHz 或 125 kHz

卡类型含义：

| 类型 | 说明 | 能写吗 |
| --- | --- | --- |
| IC 卡 | Mifare Classic 扇区卡（最常见门禁卡） | 扇区内容可写，0 块通常不可写 |
| UID 卡 | 可改写 UID 的兼容卡（CUID/FUID） | 全部可写，UID 也能改 |
| 7 字节 UID 卡 | Ultralight / NTAG 页式卡 | 页内容可写，UID 一般不可写 |
| ID 卡 | 125 kHz 低频只读卡（EM4100/TK4100） | 不可写，只能读 |

## 五、读卡

### 读单块

寻卡后在「寻卡」页下方选扇区/块，点「读块」。

软件默认先用 `FF FF FF FF FF FF` 试；不通用当前密码库里的密钥逐把试。

### 读整卡

点「读取整卡」，软件会：

1. 逐扇区尝试认证
2. 认证通过的扇区读出 4 个块
3. 认证失败的标红
4. 生成 `{uid, sectors: [[block0..3], ...], keys: [...]}` 结构

读完整卡后可以「保存到卡夹」，之后随时看、随时对比、随时写回。

### 关于密钥

读卡需要密钥。软件按以下顺序找：

```
会话里已破解的密钥 → 本卡历史库 → 全局密码库 → 界面输入的密钥 → 默认 FFFFFFFFFFFF
```

每把都拿真机认证一次，**认证不过就明确报错**，不会静默读出一堆 0。

所以如果卡是全加密的（默认密钥都不通），要先「破解」。

## 六、写卡

### 写之前：先备份

**强烈建议**：写任何卡之前先「读取整卡」并保存到卡夹。写坏了还能写回去。

### 选写入模式

「寻卡」页 → 写卡区 → 模式选择：

| 模式 | 命令 | 适用 | 速度 |
| --- | --- | --- | --- |
| 极速写卡 | `0x16` | 大多数可写卡 | 最快 |
| 普通写卡 | `0x18` | 极速模式不成功时 | 中 |
| 带密钥类型写卡 | `0x08` | 需要指定 KEY A/B 时 | 慢 |

不确定就用「极速」，不行再换「普通」。

### 写一个块

1. 选块号（0 ~ 63，1K 卡 0~63，4K 卡 0~255）
2. 在输入框填 16 字节的 hex，比如 `01 02 03 04 05 06 07 08 09 0A 0B 0C 0D 0E 0F 10`
3. 勾「写后校验」（默认勾上）
4. 点「写入」

写入失败软件会自动把原内容写回去（`_restore_block`）。这个功能可以在「设置」里关。

### 写整卡

从卡夹选一张存档卡 → 「写入到卡片」→ 软件逐块写，进度条实时更新。

中途出错会停在出错块，并提示是哪个块失败。

### ⚠️ 危险块

这些块写错可能把卡写废：

| 块 | 内容 | 风险 |
| --- | --- | --- |
| 块 0 | 厂商块（UID + BCC + SAK + ATQA） | 写错导致卡不能识别 |
| 每扇区最后一块（块 3/7/11…） | 扇区尾块（Key A + 权限位 + Key B） | 写错后扇区永久锁死 |

软件在写这两类块时会弹二次确认。**确认前先读一遍原内容记下来。**

## 七、写 UID / 改卡号

### 写 UID（仅 UID 卡 / CUID / FUID）

有些「UID 卡」的 0 块是可写的，可以把 UID 改成任意值，用来复制门禁卡。

1. 寻卡，确认卡类型是「UID 卡」或显示「可写 UID」
2. 在 UID 输入框填 8 位 hex（4 字节），例如 `DE AD BE EF`
3. 点「写 UID」

软件会自动算 BCC 并构造完整的块 0：

```
[UID 4 字节] [BCC = UID0^UID1^UID2^UID3] [SAK=08] [ATQA=04 00] [8 字节 0]
```

写完会读回校验。

**注意**：普通 IC 卡（Mifare Classic 标准卡）的块 0 是出厂写保护的，写不了。

### 写卡号（0x0C）

某些定制卡支持把「卡号」写到指定位置。这个功能因卡而异：

1. 填 5 字节卡号（10 位 hex）
2. 点「写卡号」
3. 写后可以点「校验卡号」用 `0x24` 确认

### 读 ID 卡（仅蓝牙原厂）

125 kHz 低频卡（EM4100 / TK4100）：

1. 把 ID 卡贴近读卡器**背面**（低频天线在背面）
2. 点「读 ID 卡」
3. 显示 40 bit 卡号、频率档位、卡代码、设施码

## 八、破解密钥

### 场景判断

先「读取整卡」，看哪些扇区读不出来：

- **全部扇区都读得出** → 明文卡，不用破解
- **部分读不出** → 需要破解那几把密钥
- **全都读不出** → 全加密卡，需要 HardNested

### 软件端破解（快，推荐先试）

1. 「破解」页
2. 选破解方法：
   - **mfkey32**：能采到随机数的卡，秒级
   - **HardNested**：全加密卡，几分钟到几小时
3. 点「开始破解」

软件会：

1. 通过设备采集 nonce
2. 用 numba 加速穷举
3. 命中就立刻复扫其余扇区
4. 结果自动进密钥库

### 设备端破解（仅蓝牙原厂）

原厂固件自带破解能力，速度更快：

- **全卡解码** `0x22`：固件直接跑完整流程
- **静态 Nested** `0x32`：针对特定卡型
- **FM11RF08S** `0x37`：复旦微特定芯片
- **半解** `0x30`

「破解」页 → 选「设备端」→ 点开始。

### 云端 keygen（可选）

如果用官方云端服务，可以查现成的密钥库（比本地快很多）。配置方法见 [`云端Token获取教程.md`](../云端Token获取教程.md)。

不配置也完全能用——云端不可用时会自动降级到本地破解。

### 破解不出来怎么办

| 情况 | 可能原因 | 处理 |
| --- | --- | --- |
| 一直「采集失败」 | 卡片距离不对 | 让卡紧贴感应区，别动 |
| mfkey32 算不出 | 全加密卡 | 改用 HardNested |
| HardNested 太慢 | 搜索空间大 | 让它跑，或换设备端破解 |
| 破解后读块还是失败 | 密钥对但权限位不允许读 | 检查扇区尾块的访问位 |

## 九、卡夹与密钥库

### 卡夹

「卡夹」页管理已保存的卡片：

- **添加**：读完卡后点「保存到卡夹」
- **重命名**：双击名字
- **导出**：导出为 `.json` 或 `.txt` 分享给别人
- **导入**：从文件恢复
- **对比**：选两张卡 → 「对比」→ 逐块高亮差异
- **复制/粘贴**：卡内容复制到剪贴板，粘到另一张卡
- **写入**：把存档写回实体卡

### 密钥库

「密钥库」页管理所有收集到的密钥：

- 自动收集破解成功 / 认证成功的密钥
- 手动添加
- **批量验证**：拿一堆密钥逐把试当前卡，标记哪些通
- 导出为字典文件（方便给别的工具用）

密钥库是跨卡共享的——同一批门禁卡的密钥往往相同，破了一张，其余都能直接读。

## 十、手机当读卡器

> APK 1.1.0 起界面重做（液态玻璃 + 换背景 + 本机读卡），并修掉了 9 个 bug。
> 完整说明见 [`Android读卡器.md`](Android读卡器.md)。

### 手机端

1. 把 `android\NFCMiniReader.apk`（4.2 MB）传到手机
2. 安装（允许「未知来源」；从 1.0.0 升级需先卸载，签名变了）
3. 打开 App「NFC 手机读卡器」

App 默认会自动：

- 检测 NFC 状态（没开会显示「去开启 NFC」直达按钮）
- 开 NFC 读卡模式
- 启动前台读卡服务（8765），通知栏常驻
- 开始广播信标（8766）
- 屏幕常亮

界面显示：三个状态胶囊（NFC / 网络 / 卡片）、服务开关、`IP:端口`、连接数、本机读卡工具、背景设置、实时日志。

**记下那个 IP:端口**，比如 `192.168.1.5:8765`。

### 手机自己也能读卡

不连电脑也能用：

- **读取卡片信息**：UID、SAK、ATQA、卡类型、扇区数/块数/容量
- **读扇区**：输入扇区号（0~39）+ 密钥（12 位十六进制，留空默认 `FFFFFFFFFFFF`），看 4 个块的十六进制
- **复制 UID**

### 界面能换

- 液态玻璃效果可开关（Android 12+ 是 GPU 实时模糊）
- 7 套内置渐变背景 + 从相册选自己的图
- 模糊强度 0~40、浅色/深色主题

### 电脑端

1. 设备页 → 选「手机读卡器」
2. 点「搜索手机读卡器」，等 3 秒
3. 列表出 `Pixel-8 · 192.168.1.5:8765` → 点连接
4. 连不上就点「手动输入地址」，手填 `192.168.1.5:8765`

### 放卡

把卡贴到手机**背面 NFC 天线**位置（通常在摄像头附近，具体位置查手机说明书）。

手机 NFC 感应距离只有 **1~3 cm**，而且**卡片必须静止**。读整卡时别动。

### 搜不到手机怎么办

按顺序排查：

1. **同一 Wi-Fi 吗**：电脑和手机必须在同一网段（都 `192.168.1.x` 或都 `10.0.0.x`）
2. **AP 隔离**：很多路由器默认开「AP 隔离 / 客户端隔离」，会让同一 Wi-Fi 的设备互相看不见。进路由器后台关掉。
3. **Windows 防火墙**：第一次连接可能弹防火墙提示，选「允许」。
4. **端口被占**：手机设置里可以改 TCP 端口（1024~65535），改完电脑手动填新端口。
5. **换了网段**：手机切过 Wi-Fi 后 IP 变了，重新搜索。

### 能做什么

和 PC/SC 通用读卡器完全一样：寻卡、读块、写块、写 UID、写卡号、整卡导出、密钥校验。

**不能**：设备端破解、读 125 kHz ID 卡、封卡。

## 十一、常见场景配方

### 配方 1：复制一张门禁卡到 UID 卡

前提：原卡能读出来（或能破解）。

1. 原卡贴读卡器 → 寻卡 → 读取整卡
2. 「卡夹」→ 保存，命名 `门禁卡-原始`
3. 取下原卡，放上**空白 UID 卡**
4. 寻卡，确认类型是「UID 卡」且「可写 UID」
5. 回到卡夹 → 选中 `门禁卡-原始` → 「写入到卡片」
6. 进度条走完 → 完成

如果原卡 UID 也要一致，先「写 UID」改成原卡的 UID，再写扇区内容。

### 配方 2：备份自己的卡

1. 寻卡 → 读取整卡
2. 卡夹 → 保存
3. 卡夹 → 导出 JSON
4. 把 JSON 存到网盘

以后卡丢了，买张 UID 卡按配方 1 写回去。

### 配方 3：对比两张卡找出差异

1. 读卡 A → 保存为 `卡A`
2. 读卡 B → 保存为 `卡B`
3. 卡夹 → 同时选 `卡A` 和 `卡B` → 「对比」
4. 差异块高亮，直接看到哪几个字节变了

常用于：分析门禁卡里哪个块存的是房号/有效期。

### 配方 4：批量收集密钥

1. 准备一叠同系统的卡
2. 每张卡：寻卡 → 破解 → 密钥自动入库
3. 「密钥库」页能看到累积的所有密钥
4. 导出字典，给别的工具用

## 出问题了

先看 [常见问题](常见问题.md)。还没解决的话，在「帮助」页点「运行离线自检」，把报告贴出来——`%APPDATA%\NFCMiniStudio\selftest_report.txt`。
